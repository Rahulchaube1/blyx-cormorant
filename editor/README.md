# Blyx Cormorant

Separate variation in packet delivery from a constant difference between clocks.

This extension includes the Blyx Cormorant 0.1.0 source, a runnable example and completions for its public functions. It uses the Blyx Language extension for syntax highlighting and execution.

## Run in the editor

1. Open an empty file named `cormorant-demo.blyx`.
2. Type `blyx-cormorant-demo` and select **Cormorant — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
32
2
1
```

## Use Cormorant in a project

Extract the starter into a new folder. It contains `main.blyx`, the licensed framework source in `vendor/cormorant`, and a VS Code task. With the Blyx 0.2.1 compiler and host toolchain installed, run `blyxc native-run main.blyx` from that folder. Type `blyx-cormorant-` in a Blyx file to see the framework completions. [Download the starter ZIP](https://github.com/Rahulchaube1/blyxxxx/releases/download/framework-editors-v0.1.0/blyx-cormorant-starter-0.1.0.zip)
