# Cormorant starter

Separate variation in packet delivery from a constant difference between clocks.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Cormorant** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
32
2
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/cormorant) · [View the release](https://github.com/Rahulchaube1/blyx-cormorant/releases/tag/v0.1.0)
